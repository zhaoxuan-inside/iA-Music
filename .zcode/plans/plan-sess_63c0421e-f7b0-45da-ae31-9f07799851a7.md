# 仅更新 Demo：歌单屏增加「拉取 GitHub 歌单」流程（交用户确认后再谈开发）

## Context

GitHub 歌单拉取需求已入开发计划，但 Demo 歌单屏没有拉取入口。用户要求先把该流程补进 Demo 供确认；**本次只改 `demo/index.html`，不动 Flutter 代码**。

## 改动（全部在 demo/index.html）

1. **歌单屏（hubP4）**：标题行右侧加「⇣ 拉取」chip 按钮；歌单卡支持 pending 态（accent 边框 + 「n 首待提取」+ 摘要行显示「n 首待提取」）
2. **新增拉取流程页（scr-github，三步）**：
   - 输入页：GitHub raw JSON 地址输入框（预填示例 URL）+ JSON 契约说明（name / tracks[source 来源, query 搜索词, url 来源地址, artist 歌手, title 歌名, lyrics 歌词]）+ 「拉取」按钮
   - 预览页：解析出的歌单名 + 每首（歌名 · 歌手 · 来源 chip · 地址 · 歌词有无）+ 「确认导入」
   - 完成：建歌单卡（pending 态）+ 每首进入提取任务（提取进度页可见、完成后自动入库）+ WP toast 反馈
3. 拉取为**原型模拟**（内置示例 JSON + 延时模拟网络），Flutter 按此真实实现（raw.githubusercontent 拉取 + 真实下载/提取队列）

## 验证

浏览器走通：歌单屏 → 拉取 → 输入（示例 URL）→ 预览 → 确认导入 → 歌单卡出现（pending）→ 提取进度页可见任务 → toast。然后交用户确认；确认后再按已讨论的 Flutter 开发计划执行。
