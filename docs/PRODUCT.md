# iA-Music 产品设计 v3 ·「黑胶金时代」

## 定位

一句话：**本地优先的个人音乐库——把散落的音乐收进来、看得清、听得好；UI 必须优雅。**

- 面向**自用为主**的个人音乐库，按**开源项目标准**打磨
- 最高验收原则：**优雅**。听音乐是优雅的行为——克制、仪式感、内容为本、字体气质、过渡动画（五义详见 [DESIGN.md](DESIGN.md)）
- 平台：**仅 Android（arm64）**

## 三根支柱

1. **入库**：本地文件夹扫描 + 在线提取（A 层平台深度支持 / B 层任意链接）
2. **曲库**：浏览（艺人/专辑/歌曲/歌单）、拼音即时搜索、封面与信息自动补全
3. **聆听**：Media3/ExoPlayer 播放、队列、逐行歌词、会话恢复

## 设计方向

**参照 Zune / WP7 黄金时代**：纯黑画布、细字重大标题、单一 accent、全景横滑。
设计语言、色板、组件语汇、动效与逐页规格全部收敛在 [DESIGN.md](DESIGN.md)，
PRODUCT 只定功能与信息架构。

## 信息架构

**纯横滑，无底部导航栏**；返回靠系统手势；迷你播放条吸底常驻（横滑 = 切歌）。

### Hub（主页，全景横滑）

| 屏 | 内容 | 说明 |
|---|---|---|
| 负一屏 | 听法 | 会话起点统一入口（见下节），细体大字列表 |
| 1 | 正在播放 | 上次会话大磁贴（封面 + 歌名 + ▶）；无会话时是「随缘听歌」磁贴 + 最近添加封面长廊，音乐仓库始终可见 |
| 2 | 快速播放 | **Zune Quickplay**：长按艺人/专辑/歌单「固定到快速播放」，钉成磁贴墙；长按磁贴可移除 |
| 3 | 曲库 | **歌曲列表**——全部歌曲按歌名字母排序，右缘字母导航轨，点击即播；底部「音乐页」入口（分类浏览） |
| 4 | 最近添加 | 标题 + 计数行 + **两列网格多行**（新入库专辑 → 专辑详情） |
| 5 | 常听与历史 | 同上逻辑：计数行 + 两列网格（常听专辑，按播放次数排序，显示播放次数）+ 最近播放网格（Zune History） |
| 6 | 歌单 | 同上逻辑：计数行（n 个歌单 · n 首）+ 两列网格（歌单卡 → 歌单详情）；**GitHub 歌单**入口（粘贴 raw JSON 清单 URL，契约见下文「内容来源」） |
| 屏末 | 设置 | 低调入口 → 设置页；**设置：主题色、存储（独立配置项 → 子页：音乐目录交互式更改、曲库统计、索引状态）、收集区块（A 层登录、B 层粘贴链接提取）+ 独立的「提取与补全进度」子页（进度实时跳动）、语言、关于已并入设置页**，不再单独成屏

Hub 共 **8 屏**（负一屏 + 六主屏 + 设置）。屏序按使用习惯排布：高频在前（怎么听 → 在播 → 找歌），流水信息居中（新货 / 常听历史 / 歌单），管理类靠后（设置）。

### 音乐页（分类菜单 + 列表页）

- **菜单页**：`音乐` 标题 + 分类浏览大字入口（艺人 / 专辑 / 歌曲 / 歌单，带数量）+ 流派 chips（点入流派详情）；搜索走应用栏 🔍，不设重复入口；Hub 曲库屏底部的「音乐页」入口到达
- **列表页**：点入分类后进入对应 pivot 列表（艺人 | 专辑 | 歌曲 | 歌单 四段横滑），歌曲/艺人/专辑列表带**右缘字母速查轨**
  （拖动时屏幕中央弹出大字母）。列表项**长按**呼出 WP 式上下文菜单；左缘右滑返回菜单
（播放 / 加歌单 / 喜欢 / 加入队列 / 查看专辑）。

### 搜索

- 入口 = 各 Hub 页页头右上角 🔍 + 曲库页/音乐页入口，一步可达
- 进页即聚焦键盘，**即时分组结果**：歌曲 / 艺人 / 专辑 / 歌单
- 拼音全拼 + 首字母命中；无输入时显示提示与「从链接提取」入口
- 点击 = 播放（连续动效飞升）；长按 = 上下文菜单
- **在线来源**：同一页内聚合搜索已登录的 B 站 / YouTube；点结果直接加入提取队列
- **从链接提取**：搜索页/首页/设置均可直达，粘贴 B 站 / YouTube / 直链音频

### 播放域

- **Now Playing** = Pivot 三屏：`播放 | 歌词 | 队列`；播放屏**整页横滑 = 上一首/下一首**
- 歌词屏：纯黑，当前行 accent 细体大字，点行跳播，长按调偏移
- 队列屏：拖拽重排、移除、「下一首播放」插播
- 迷你条：封面 + 歌名 + accent 进度线，吸底；左右横滑切歌；点击展开 NP

## 播放方式

### 会话起点（一期全部）

| 方式 | 说明 |
|---|---|
| 顺序播放 | 集合按序播 |
| 集内随机 | 当前集合内打乱 |
| 随缘听歌 | 全曲库随机，hub 屏 1 磁贴一点即开 |
| 按专辑连播 | 完整专辑体验 |
| 常听 | 播放次数 Top N |
| 最近添加 | 新入库电台 |
| 喜欢电台 | 从红心歌出发随机 |
| 历史回放 | 播放历史直接变队列 |
| 歌单 | 人工集合 |

### 队列行为（一期全部）

循环模式（单曲循环 / 列表循环 / 随机不重复）、队列编辑（拖拽 / 移除 / 插播）、睡眠定时（15/30/60 分钟淡出）。

### 暂缓池（三期起，按需捞回）

艺人电台、年代电台、每日随缘、随机轮盘、无限电台、智能歌单、场景/心情标签、按相似度推荐。

## 内容来源

- **本地**：文件夹扫描入库（isolate 解析、批事务、FTS 拼音索引、文件监听增量）
- **A 层平台**：**B 站**（扫码登录）、**YouTube**（cookie 导入）——站内搜索 → 选集 → 批量提取，字幕自动转歌词，进度可见；均为内置解析器（B 站走 DASH 音频流 / YouTube 走 InnerTube），无 yt-dlp
- **B 层直链**：不登录不搜索，粘贴**直链音频 URL** → HTTP 下载入库；B 站 / YouTube 页面链接由 A 层解析器承接，其余站点页面链接不支持
- **GitHub 歌单**：粘贴 raw JSON 清单 URL → 契约 `{name, tracks:[{source, url, title, artist, query, lyrics}]}` → 建歌单（pending）+ 逐首入提取队列 + 歌词即刻落盘
- **存储（统一原则）**：所有音乐存放在**同一个音乐目录**（默认系统 Music 目录，可在收集页交互式更改），**曲库不区分来源**——提取结果与本地文件同等对待，无来源标记
- **凭据（自知）**：平台 cookie 明文存于应用沙箱内的曲库设置 KV，不外传；备份 / 导出曲库数据时会一并带出，注意保管

## 分期

### 一期（可发布纵切）

- 本地扫描入库 + Hub 七屏 + 收藏 pivot（字母速查）+ 详情页
- 搜索（即时分组 + 拼音）
- 播放域全套：Media3/ExoPlayer、队列/循环模式/睡眠定时、会话恢复、缺失跳过、后台/锁屏媒体会话
- 上表全部会话起点
- 歌词：内嵌 / .lrc / LRCLIB，逐行沉浸、点行跳播、偏移调整
- 歌单 / 喜欢 / 历史
- Zune 设计系统 + accent 自选 + 动效三件套 + 首启 onboarding（两步：选色仪式 → 选音乐目录，完成即进 Hub）

### 二期

- A 层提取：B 站扫码、YouTube 登录、站内搜索、批量提取、字幕转歌词
- B 层：任意链接提取
- **元数据补全队列**（已实现，指纹链优先）：任何缺失歌手/歌词的曲目自动入队，双链反向识别后写回标签，缺失期间以默认信息展示
  - **指纹链（真·音频内容识别，不依赖文字线索）**：Android MediaCodec 解码（上限 110s）→ 下混/重采样 mono/11025/s16 → chromaprint FFI 算压缩指纹（base64）→ AcoustID /v2 lookup（时长秒锚定）→ 采纳歌名/歌手 → LRCLIB 拉歌词
  - **回退链（NLP + 网络搜索，非 LLM）**：本地分词滤噪构造候选搜索词 → LRCLIB 搜索 → 时长锚定 ±3s → 跨查询投票 → 高置信采纳
  - **chromaprint vendored**：pub 包 `chromaprint 0.2.1` 发布件缺 C++ 源码，仓库内以 `third_party/chromaprint-ffi/` 补全——pub 包壳（Dart FFI 绑定 + 平台壳）+ chromaprint 1.5.1 `src/` 全量 + kissfft（master 版整组 6 文件，勿与旧版混搭）+ 内部 avresample（无需 ffmpeg）；pcm 由 Android MediaCodec 提供，`audio_processor.cpp` 仅作独立编译不依赖外部解码库
- 封面自动补全链（内嵌 → 同名图 → 在线 → 色块）
- 搜索页「曲库 | 在线」范围切换

### 三期（暂缓池）

听法扩展（见上）、云同步（WebDAV）、ASR 歌词（SenseVoice）、EQ。

## 明确不做 / 暂缓

- Windows / Linux 桌面端（聚焦 Android；需要时从 `legacy/v1` 回捞）
- 浅色主题——黄金时代只有黑
- A 层之外的任何平台深度支持（网易云、QQ音乐等不做登录级集成）
- 把设计叙事写进代码注释——设计决策只活在 `docs/` 里
- 一次性铺开全部功能——每期都是可发布纵切
