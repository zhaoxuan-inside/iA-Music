# iA-Music 产品设计 v2

## 定位

一句话：**本地优先的个人音乐库——把散落的音乐收进来、看得清、听得好。**

三根支柱：

1. **入库**：扫描本地文件夹 / B 站提取（P2），音乐自动归位
2. **曲库**：浏览（曲目/专辑/艺术家）、拼音搜索、封面与信息自动补全
3. **聆听**：mpv 播放、队列与随机、逐行歌词、会话恢复

## 平台

**仅 Android（arm64）**。Windows/Linux 不作为产品端（v1 的 Windows 代码
在 `legacy/v1` 分支可随时回查；`packaging/mpv` 里的 Windows dll 仅服务
本机 `flutter test` 的宿主构建，不随产品分发）。

## 信息架构

- 底部 4 Tab——曲库 / 搜索 / 歌单 / 设置；悬浮迷你播放条。
- 横屏 / 宽屏（≥720dp）：左侧栏 + 常驻迷你播放条（同一套组件自适应）。
- 播放域全局唯一，冷启动恢复上次会话。

## 设计语言

- Material 3 + 品牌绿 `#4BE0A3`（深色基板 `#0F1013/#1A1B20/#23242B`；
  浅色基板 `#F5F6F8/#FFFFFF/#ECEEF1`）。
- 红心 `#FF5C7A` 仅收藏语义，不随封面取色漂移。
- 封面动态取色：当前播放封面的主色 seed 派生 accent 族（`ColorScheme.fromSeed`）。
- 所有颜色/间距/字号收敛在 `lib/app/theme/design_tokens.dart`，UI 禁止硬编码色值。

## 功能范围（分期）

### P1（本期）
- 文件夹扫描入库（isolate 解析、批事务、FTS 拼音索引、文件监听增量）
- 曲库三视图 + 专辑/艺术家详情 + 封面链（内嵌→同名图→在线→色块）
- 播放（队列/随机/上下曲/seek/音量/会话恢复/缺失跳过/媒体会话）
- 歌词（内嵌/.lrc 旁车/LRCLIB 获取，逐行滚动、点行跳播、偏移调整）
- 歌单 / 喜欢的音乐 / 播放历史
- 设置（文件夹管理、外观、语言、关于）+ 轻量 onboarding

### P2
- B 站：扫码登录、关键词搜索、链接提取入库（yt-dlp）、字幕转歌词

### P3
- 云同步（WebDAV 先行，墓碑/冲突副本模型沿用 v1 设计）
- 本地 ASR 歌词（SenseVoice）、EQ、识别修正、随机轮盘

## 明确不做（v1 教训）

- Windows / Linux 桌面端（v2 起聚焦 Android；需要时从 `legacy/v1` 回捞）
- 把设计叙事写进代码注释——设计决策只活在 `docs/` 里
- 一次性铺开全部功能——每期都是可发布纵切
