# iA-Music 设计语言 · Zune 黑金时代

设计参照 **Zune / WP7 黄金时代**的 Metro 语言。本文是唯一视觉依据；
代码中所有颜色/字号/间距/动效参数收敛在 `lib/app/theme/` 下的 token 文件，
UI 不允许硬编码。

## 一、基本法（五条）

1. **纯黑画布 + 封面环境色**：`#000000` 一路到底，但 **Hub / Quickplay / Now Playing / 详情页**
   允许当前封面的颜色占据背景：失焦封面 + 黑纱 + 暗角，像 Zune 软件那样
   「换一首歌，整个房间换一次光」。列表、设置、搜索保持纯黑，保证文字与操作清楚。
2. **排版驱动**：大标题一律细字重（Light）。拉丁字符用 **Selawik**
   （微软开源 Segoe UI 替身，OFL 许可），中文用系统黑体细字重。字本身就是装饰。
   > 当前构建未内置字体文件，Android 上以系统无衬线细体回退；接入 Selawik 时
   > 只需在 `pubspec.yaml` 注册并在主题里设 `fontFamily`，不动任何页面代码。
3. **Accent 即灵魂**：全 App 只允许 accent 一种彩色。进度线、当前行、选中态、
   pivot 指示、字母轨高亮，都用它；其余一律黑白灰。用户可在 WP 经典色板中自选。
4. **内容即界面**：封面满铺、列表项之间不加框、按钮是文字加细线而非色块；
   操作靠**长按上下文菜单**（WP 式黑底升起菜单），不用滑动操作、不用 FAB。
   大封面必须带**黑胶倒影**：封面落在黑底上，而不是浮在页面里。
5. **动效三件套 + 招牌交互**（缺席即不合格）：
   - **翻页 Flip（磁贴翻开）**：页面跳转，整页绕横轴翻入/翻出（翻页前后共用同一「倒下」姿态，像翻过一张卡片），360ms；被点磁贴自身先绕纵轴翻开 88°，300ms
   - **连续 Continuum**：列表项点击后飞升，落成详情页大标题，250ms
   - **视差 Panorama**：Hub 横滑时背景巨字与页标题以 0.5～0.62x 速度跟随，内容 1:1
   - **整页横滑切歌**：NP 播放屏与迷你条，左右横滑 = 上/下一首，200ms 封面交叉淡入

## 二、色板

### 基板（固定，不随任何东西变化）

| token | 值 |
|---|---|
| canvas | `#000000` |
| textPrimary | 白 @ 92% |
| textSecondary | 白 @ 55% |
| textTertiary | 白 @ 35%（只准用于可弃信息） |
| separator | 白 @ 6% |
| onAccent | `#FFFFFF` |
| error | `#E51400` |

### Accent（用户可选，默认第一项）

默认 **Zune 洋红 `#F1006E`**（经典 Zune 软件同款）。其余为 WP7 经典色板：

```
Zune洋红 #F1006E（默认）   洋红 #D80073   经典蓝 #1BA1E2   青绿 #00ABA9
柠绿 #A4C400   绿 #008A00   橙 #F09609   粉 #F472D0   紫 #A200FF
红 #E51400   棕 #A05000
```

规则：accent 只作**小面积点缀**（线、字、小图标），禁止大面积色块铺底。

## 四、布局语法

- 内容满铺到屏幕边缘；水平安全边距 24；列表行高 56（歌曲）/ 72（专辑、艺人）
- 无卡片、圆角 ≤ 2px、无边框；分隔靠 1px 白 6% 细线
- **页头系统**：每屏统一为 `kicker（accent 10.5 全大写字距）→ 细体大标题（Hub 44 / 页面 34）→ 副题（白 35%）→ 32×2 accent 短横`；标题永远活在内容里
- **顶栏**：透明融入黑底，仅返回箭头 + 右上 🔍/⋯，不设标题栏底色
- **底部应用栏**（详情页专用）：90% 黑半透明条，圆形小图标（播放全部 / 随机 / 收藏），
  WP7 应用栏的血统
- **字母速查轨**：右缘竖排小字母，拖动时屏幕中央弹出大字母（Light 64，accent）
- **磁贴 Tile**：Hub 内容一律 1:1 封面磁贴，零圆角零阴影，标题在磁贴下方细体
- **黑胶倒影**：大封面（≥ 120）下方加 30% 高度的镜像倒影，向下渐隐；列表小封面不加深影
- **迷你条**：整宽吸底黑条（不悬浮、不圆角）+ 顶部 2px accent 进度线；左封面、中标题、右播放/展开

## 五、动效

| 场景 | 规格 |
|---|---|
| 页面跳转（磁贴翻开 Flip） | 整页绕横轴 rotateX 62° 翻入/翻出（origin 50% 62%），360ms easeOutCubic；被点磁贴自身绕纵轴翻开 88°，300ms |
| 进页逐条翻入（Turnstile Feather） | **WP8 pivot 招牌**（Silverlight Toolkit `TurnstileFeatherEffect`）：列表/网格条目绕纵轴 84° 依次翻入 + 淡入，420ms easeOutCubic，条目错峰 45ms（≤11 条参与，只播一次；滚动出的新条目不重播）。Hub 八屏内容区与曲库/最近添加/常听历史/歌单/快速播放的条目生效 |
| 快速播放磁贴翻面（Live Tile Flip） | **WP8 Music+Videos Hub 马赛克磁贴**：磁贴周期性绕纵轴 3D 翻面 900ms easeInOutCubic；全局时钟 2.5s 一拍，每块磁贴按标题种子取 3~5 拍周期与相位，永不同步；背面 = 黑底 + 首字水印 + 「点按播放 · 长按固定/解除」。时钟只在生产开启（测试静默） |
| 长标题走马灯 | **WP 音乐播放器 ticker**：迷你条歌名单行溢出时 62px/s 匀速横滚，起始停 0.9s、回卷前停 1.5s 循环；不溢出即普通文本 |
| 按压 Tilt | **Silverlight Toolkit tilt**：按下 0.972 缩放 140ms easeOutCubic，抬起回弹；纯黑画布无水波的等位手感。大字行/歌曲行/快速播放磁贴生效 |
| 切歌文字过渡 | 迷你条 / 屏1 / NP 的标题与歌手随切歌 220ms 上滑淡入淡出；封面交叉淡入见下两行 |
| 列表项 → 详情（连续） | 被点项飞升至详情页标题位，250ms |
| Hub 横滑（视差） | 背景巨字 0.34x、页标题 0.62x、竖分割线 0.5x；内容 1:1 |
| Pivot 横滑 | 内容 1:1，头部当前项 Light 放大过渡（AnimatedDefaultTextStyle 200ms），accent 下划线 200ms |
| 封面切换（环境光） | 620ms 失焦色雾交叉淡入；大封面 260ms 交叉淡入 |
| 整页横滑切歌 | 200ms，封面交叉淡入 |
| 迷你条 → NP | 上滑展开 260ms（6% 位移 + 淡入） |
| 长按菜单 | 底部升起 200ms + 后景压暗 40% |
| 操作反馈 | 即时可视操作（喜欢/随机/循环等）只以控件状态 + 弹跳动画确认，不弹文字通知 |
| 睡眠定时淡出 | 音量 5s 线性淡出 |

> 动效令牌全部收敛在 `design_tokens.dart` 的 `IaMotion`；组件实现在 `lib/ui/shared/wp_motion.dart`。
> 调研参照：WP8 内置应用与 Music+Videos Hub 的 Turnstile Feather / Live Tile Flip /
> Tilt（Silverlight for Windows Phone Toolkit），Xbox Music 8.1 的「滑动封面切歌」。

## 六、交互法则（WP 血统，与视觉同等重要）

1. **无顶部导航栏**：内容即界面——大标题活在内容里；页面顶端只有内容，没有 ‹ 返回钮、没有工具条
2. **返回 = 系统手势**：Android 左缘右滑（WP 硬件返回键的等位）；应用内不提供任何可见返回控件
3. **底部应用栏**：圆形小图标一行 + 右侧 `⋯`；点 `⋯` 升起文字菜单（无遮罩，黑底 accent 左缘线）；搜索住在应用栏 🔍，不在顶部
4. **横向流转**：Hub 全景横滑，下一屏内容从右缘 peek 探出引导滑动；收藏页 pivot 头部即导航；操作靠长按上下文菜单
5. **搜索页是内容页**：大号细体输入框（下缘线）+ 即时分组结果，无「搜索」按钮
6. **反馈用动效，不用文字**：喜欢/随机/循环/清空等即时可视操作，只以控件状态变化 + 弹跳动画确认，不弹文字通知；文字通知只留给后台事件（提取完成、补全完成），且采用 **WP toast 形态：顶部整宽横条从顶边滑入，第一行来源标题（accent 小字）+ 第二行消息**，直角无气泡，约 2.6s 自动收回
