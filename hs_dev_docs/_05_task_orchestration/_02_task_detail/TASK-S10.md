# 任务详单：S10 三端打包与交付预演（BUILD 阶段 4 / TASK-02）

## 归属与映射
- REQ 映射：**无直接业务 REQ（交付切片）**——产出进阶段 6 的 DELIV-04/05（交付可用性与结论）；超出=交付说明不属于功能验收
- DEC-008 ④ 分发基线：Android 8+ / Win10 x64 / Ubuntu 22.04+·Debian 12+（AppImage+deb）；ffmpeg 用 LGPL 构建

## 目标
三端安装包 + 安装/数据迁移/恢复说明 + 版本钉死检查 + 交付演练表（阶段 6 输入）。

## 边界
- 不含商店上架/签名证书购买（个人分发基线）；不含 CI 流水线（治理 off）

## 输入
DETAILED-DESIGN §4（部署形态/机密四层）；TECH-SELECTION §5 版本；ADR-0001

## 输出
`build/` 产物（apk/appimage/deb）三份 + `DELIVERY-NOTES`（安装/迁移/恢复/限制/未实现清单）+ 交付演练记录

## DoD
1. 三端产物冒烟：安装→启动→导入仓库→播放→退出全路径（各端 1 条证据）
2. 版本锁定核对表（pubspec/捆绑二进制 vs ADR-0001 逐行）
3. 数据迁移与恢复说明可操作（drift 迁移链 v1 起步=首版无迁移；「恢复」=新设备从同步恢复路径）
4. 限制与未实现项明确（如 RV 未收敛项等，逐条列出）

## 测试 seam
真机+真桌面端冒烟演练（每端一次），记录进 QA log；无自动化集成（治理 cicd=off）

## 前置外部条件
Android 签名（debug 签名可分发 MVP）；桌面打包工具（AppImage/deb 构建链路随身 S0 工具装齐）
