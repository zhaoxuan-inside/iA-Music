## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦 (Status Quo)**：在线音乐 App 没有"我的曲库"的沉浸感；本地播放器又都是"文件夹树/表格"，浏览体验工程化、无惊喜。
- **用户雇佣任务 (JTBD)**：`When` 我打开应用时只是想"听点什么"或"找一首特定的歌"，`I want to` 一眼看到可以马上开听的入口（随机/最近入库/我的歌单）或快速搜到目标，`so I can` 零思考进入音乐。
- **惊喜时刻 (Aha Moment)**：打开应用首页（音乐空间），顶部就是"随机——随机播放我的曲库"，一点就开听；下面的"最近入库"正好是我昨天提取的歌。
- **冷启动体验 (FTUE)**：曲库为空时三 Tab 各有引导（音乐空间→选目录/粘贴链接；搜索→先有音乐再搜；我的→引导红心）。

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

### 3.1 音乐空间页

| 区块 | 规则 | 空态微文案 |
|---|---|---|
| 随机 | 绿渐变大卡显示当前/默认随机池（全部曲库减去少播名单）；点击即随机播放 | "曲库是空的。先导入音乐，才能随机播放" |
| 最近入库 | 最近 20 首，横滑卡列；点击单曲播放 | 空：隐藏区块 |
| 我的歌单 | 歌单卡横滑 + "新建歌单"末卡 | 空：显示"创建第一个歌单"引导卡 |
| 最近播放 | 最近 10 首去重 | 空：隐藏区块 |

### 3.2 搜索

| 项 | 规则 | 微文案 |
|---|---|---|
| 输入 | 300ms 防抖；≥1 字符即搜；支持拼音首字母（如 `yhw` → 夜黑雾） | 占位："搜索歌曲 / 歌手 / 专辑" |
| 结果分区 | 曲目 / 歌手 / 专辑 / 歌单 / 来源（UP 主）分区展示，每区最多 3 条 + "查看全部" | — |
| 排序 | 精确匹配 > 前缀 > 包含；同权重按最近播放 | — |
| 空结果 | "没有找到与「XX」相关的音乐" + 建议（检查拼写/换个关键词） | — |

### 3.3 我的

| 区块 | 规则 |
|---|---|
| 数据卡行 | 3 张图像统计卡：喜欢(N) / 历史(N) / 本地(N)——豆瓣 FM 同款卡位（含"本地"卡，DEC-003；图像卡样式对齐官网实拍，DEC-006） |
| 歌单区 | 标题"我的歌单" + 歌单列表（封面/名称/曲目数）+ "创建/导入歌单"入口（副题：把喜欢的音乐装进歌单） |
| 入口 | 设置（含同步中心、仓库管理、音效、歌词模型、关于/合规声明） |
| 统计卡点击 | 红心卡 → 红心歌单；历史卡 → 历史列表；本地卡 → 曲库列表（P-LIBRARY） |

### 3.4 迷你播放条（跨 Tab 常驻 · DEC-011 D11-4）

| 项 | 规则 |
|---|---|
| 展示 | Tab 栏上方**通栏**：封面缩略（圆角 8）+ 歌名 - 歌手（跑马灯）+ 播放/下一首 + 条底缘一线进度（accent 色） |
| 点击 | 点击条体 → 展开沉浸播放页 |
| 空态 | 无播放会话时隐藏（不占位） |

### 3.6 曲库 Tab（DEC-011 D11-2 新增）

| 项 | 规则 |
|---|---|
| 内容 | P-LIBRARY 曲库列表整页升格：歌曲/歌手/专辑分段浏览（复用 `ui/library/library_list_page.dart` 现有逻辑） |
| 顶部 | 页级大标题「曲库」+ 曲目计数；检索入口跳转搜索 Tab |
| 我的页关系 | 「我的」页"本地(N)"数据卡保留（计数与跳转一致），不因 Tab 直达而移除 |

### 3.5 「随机」页（经典兆赫 · 唱片轮盘，DEC-006 D6-7）

| 项 | 规则 |
|---|---|
| 形态 | 唱片轮盘：5 槽位歌曲海报卡沿左侧弧线层叠（当前卡=正在播放，方形焦点、最上层；上/下方为横条卡）；左沿出血；层次仅靠旋转渐进 + z 序（静态卡无模糊/无缩放） |
| 切歌 | **仅上滑**（无下滑、无点击切歌）；手动上滑，或当前曲目播放结束自动上转；单轮不重复 |
| 手势 | 任意方向拖拽整盘跟手（上移 + 绕转盘轴心微旋转），松手回弹；过渡 `.55s cubic-bezier(.32,.72,.28,1)` |
| 信息区 | 「随机」▾ / 歌名 / 歌手 / 进度条 / 时刻，随焦点卡同步（右下列，128px） |
| 控件 | 🗑 = 移出随机池（少播名单，语义同播放页）/ ⏸ / ♥；贴底出血 |
| 主题 | 暗色同暗房底；浅色纯白底 + 卡阴影减弱 + 薄荷/柔粉专项控件色（不沿用全局 accent） |
| 空态 | 曲库为空 → "曲库是空的。先导入音乐，才能随机播放。" + 导入 CTA |

### 业务分支规则

1. **随机曲池**：排除"少播名单"；池不足 10 首时用全库补满；单次随机一轮内不重复；
2. **搜索与文件缺失**：结果中缺失文件曲目灰显+标注；
3. **大曲库性能**：1 万首下搜索输入到结果 ≤ 300ms（本地索引）；
4. **「随机」页轮盘（DEC-006 D6-7）**：与随机会话共享同一随机池与当前曲——轮盘上的手动上滑/播完自动上转即"下一首"语义；垃圾桶与单轮不重复规则一致。

## 5. 页面四态要求

- **Empty**：音乐空间页空态（引导导入）、搜索空历史（显示"试试搜索歌手或歌名"+ 热门来源标签）、我的页空态（红心/历史/歌单引导）；
- **Loading**：搜索"搜索中"轻提示；音乐空间页模块化加载（先显已就绪区块）；
- **Populated**：如上述区块规则；
- **Error**：搜索索引损坏 → "本地索引需重建" + 「重建索引」按钮（曲库完整性不受影响）；
- **「随机」页四态**：Empty=曲库为空引导导入；Loading=封面解码中首字母占位（无假骨架）；Populated=轮盘 + 信息区 + 控件；Error=解码失败顶部提示并自动上转下一首（同播放页）。
