## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦 (Status Quo)**：本地播放器首次启动大多直接把用户丢进空列表；设置项几百个不知道怎么配；对"这个 App 能干什么"毫无头绪。
- **用户雇佣任务 (JTBD)**：`When` 我装好这个应用第一次打开，`I want to` 用两步就把我的音乐接进来（甚至立刻试一首 B 站的歌），`so I can` 在 30 秒内听到自己的音乐并理解这个应用的脾气。
- **惊喜时刻 (Aha Moment)**：一个链接从 B 站到沉浸播放，全程不超过三个阶段界面——首次启动就能体验（FTUE 直接复刻主 Aha）。
- **冷启动体验 (FTUE)**：本特性即 FTUE 本体：① 选/建仓库（可扫描已有音乐）→ ② 可选"粘贴一条 B 站链接试一首"（无账号也可低码率试听/入库，合规声明确认）→ 完成进入音乐空间（随机卡高亮）。

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

### 3.1 FTUE 步骤

| 步骤 | 内容 | 规则 | 微文案 |
|---|---|---|---|
| 步骤 1（必选） | 选择音乐仓库 | 提供建议目录（系统"音乐"文件夹）一键采用，或"选择其他文件夹"；选择后立即扫描并显示"已发现 N 首"实时计数 | 标题："你的音乐放在哪？" |
| 步骤 2（可选） | 试一首 B 站链接 | 粘贴框 + "跳过，直接开始"；若使用则先弹合规声明确认 | 标题："试试提取你的第一首歌" |
| 完成 | 进入音乐空间（随机卡高亮） | 若库为空且未试提取 → 空态引导 | "开始聆听" |

### 3.2 设置信息架构

| 分组 | 设置项 |
|---|---|
| 音乐仓库 | 仓库列表（添加/重命名/重新扫描/移除）、自动扫描开关、封面刮削开关、提取保存位置、文件命名规则（默认/自定义模板） |
| 播放 | 默认循环模式、倍速默认值、少播名单管理（清空） |
| 音效 | 均衡器入口（预设/EQ） |
| 歌词 | 歌词模型管理（下载/删除/查看体积）、歌词字号 |
| 同步 | 同步中心入口（通道配置/状态/冲突副本/墓碑记录） |
| 外观（DEC-005） | 界面主题（深色/浅色/跟随系统）、界面语言（中文/English/跟随系统）；即时生效、本地持久化 |
| 关于 | 版本号、开源许可、合规声明（可回看）、隐私说明（无遥测声明） |

### 3.3 业务分支规则

1. **跳过 FTUE**：提供"跳过" → 直接进音乐空间空态（空态仍有完整导入引导，无死胡同）；
2. **首次合规**：提取功能第一次触发（FTUE 或常规入口）时展示声明，确认后不再展示，可在关于页回看；
3. **仓库改为空**：删除所有仓库 → 曲库进入"未配置"引导态；
4. **迁移/重装**（配合同步）：新设备 FTUE 增加"从同步恢复"捷径（已有通道配置时）。

## 4. 需求原子分解与行为驱动验收标准 (Requirements & Functional DoD)

### 4.1 核心需求原子分解清单

| 需求编号 | 需求名称与规则简述 | 关联动作 | 验收物理证据 | 优先级 |
|---|---|---|---|---|

| `REQ-ONB-02` | 建议目录一键采用 | 步骤 1 点"使用『音乐』文件夹" | 立即开始扫描并显示实时计数 | P0 |

### 4.2 行为驱动产品验收场景 (Gherkin Scenarios)

```gherkin
Feature: 首次引导与设置

  Scenario: REQ-ONB-01/02 首次冷启动 30 秒闭环 (Happy Path / FTUE)
    Given 用户全新安装应用且系统音乐文件夹内有 120 首音乐
    When 用户首次启动并点击"使用『音乐』文件夹"
    Then 界面开始扫描并实时显示"已发现 N 首"
    When 扫描完成用户点击"跳过，直接开始"
    Then 进入音乐空间，随机卡片可用，曲库计数为 120

  Scenario: REQ-ONB-03 合规声明门禁 (Guardrail)
    Given 用户在引导第 2 步粘贴了 B 站链接且尚未确认合规声明
    When 用户直接点击"开始提取"
    Then 弹出合规声明，未确认前不发起任何下载
    When 用户确认后
    Then 提取流程正常继续，且后续不再重复弹出

  Scenario: REQ-ONB-05 歌词模型的下载与清理 (Settings)
    Given 用户从未下载过歌词模型
    When 用户进入设置 → 歌词模型并点击"下载模型"
    Then 显示下载进度与体积；完成后状态为"已就绪"
    When 用户点击"删除模型"
    Then 显示占用空间已释放，歌词生成入口回到"需下载模型"状态

  Scenario: REQ-ONB-07 主题切换即时生效 (Theme)
    Given 用户处于深色主题
    When 用户在设置 → 外观中选择"浅色"
    Then 全应用立即切换为浅色主题，无残留深色硬编码块
    And 重启应用后仍保持浅色

  Scenario: REQ-ONB-08 界面语言切换 (Language)
    Given 用户界面语言为中文且队列中有《夜航》
    When 用户在设置 → 外观中将语言切换为 English
    Then 界面标签变为英文，但曲名《夜航》与歌手信息保持原样
    And 随后的歌词生成任务按英文界面语言约定的输出执行
```

## 5. 页面四态要求

- **Empty**：无仓库（设置向导入口卡）；模型未下载（引导下载）。
- **Loading**：扫描进度、模型下载进度。
- **Populated**：设置六组列表、关于页信息。
- **Error**：目录不可读 → "无法访问该文件夹（权限或设备未连接），请重新选择"；模型下载失败 → 重试 + 换源说明。
