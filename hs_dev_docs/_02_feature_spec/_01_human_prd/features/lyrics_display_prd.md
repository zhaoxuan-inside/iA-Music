## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦 (Status Quo)**：本地歌曲大多无歌词；偶有 .lrc 也常与音频不同步（偏移几秒），只能忍着或手动改。
- **用户雇佣任务 (JTBD)**：`When` 我想跟着歌词听一首歌，`I want to` 看到逐行高亮、可点跳转的歌词（必要时微调同步偏移），`so I can` 跟着唱/理解歌词而不被不同步打断。
- **惊喜时刻 (Aha Moment)**：歌起字亮，点击任意一行歌词立即跳转——和在线 App 一样的体验，但那首歌只是我硬盘里的一个文件。
- **冷启动体验 (FTUE)**：无歌词曲目 → 歌词页显示"这首歌还没有歌词" + 两个出路：「生成歌词（本地 AI）」/「手动粘贴歌词」。

---

## 2. 交互形态比选与取舍 (Approaches & Trade-offs)

| 评估维度 | 方案 A（推荐采纳） | 方案 B（备选弃用） | 取舍理由 |
|---|---|---|---|
| **歌词入口** | 播放页 `唱片 ⇄ 歌词` 图标切换 / 上滑展开 | 独立菜单跳转 | 与在线播放器心智一致，最顺滑 |
| **歌词来源优先级** | 同目录同名 .lrc > 音频内嵌标签 > 用户手动粘贴 | 仅 .lrc | 兼容多种既有资产；手动兜底 |
| **偏移调整** | 歌词页内长按/按钮 ±0.5s，实时预览，保存到本地 .lrc | 设置页全局偏移 | 单曲粒度最实用 |

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

| 项 | 规则与边界 | 默认值与微文案 |
|---|---|---|
| 来源优先级 | `.lrc`（同目录同名）→ 内嵌标签（USLT/LYRICS）→ 无 | — |
| 时间轴 | 标准 .lrc `[mm:ss.xx]`；支持多时间标签一行 | — |
| 翻译歌词 | .lrc 双行/`[翻译]` 约定：第二语言行以稍小字号展示在原文下方 | 自动识别 |
| 偏移范围 | -10s ～ +10s，步进 0.5s | 默认 0s；微文案："歌词偏移 0.5 秒" |
| 点击跳转 | 点击任意行 → 跳转到该行时间戳 | — |
| 手动粘贴 | 纯文本或 .lrc 均可；纯文本按"无时间轴歌词"静态展示 | "粘贴歌词（支持 LRC 格式）" |
| 保存位置 | 与音频同目录同名 `.lrc`（不修改音频文件本体） | 保存时提示"已保存为 歌曲名.lrc" |

### 业务分支规则

1. **无时间轴歌词**（纯文本）：静态展示不可滚动高亮，仍可调字号；
2. **偏移保存**：调整偏移后若来源是内嵌歌词 → 导出为同目录 .lrc 文件（不写回音频文件）；
3. **超长歌词**：行数不限；自动随播放居中滚动。

## 4. 需求原子分解与行为驱动验收标准 (Requirements & Functional DoD)

### 4.1 核心需求原子分解清单

| 需求编号 | 需求名称与规则简述 | 关联动作 | 验收物理证据 | 优先级 |
|---|---|---|---|---|
| `REQ-LYR-01` | 歌词来源解析与展示 | 播放带 .lrc 的曲目并切到歌词页 | 逐行高亮随播放推进 | P0 |
| `REQ-LYR-02` | 点击跳转 | 点击第 N 行 | 播放进度跳到该行时间戳 | P0 |
| `REQ-LYR-03` | 偏移调整与保存 | 长按"同步偏移"→ +0.5s → 保存 | 高亮与听感对齐；同目录生成 .lrc | P0 |
| `REQ-LYR-04` | 手动粘贴歌词 | 无歌词 → 粘贴 | 粘贴内容立即可用；可保存为 .lrc | P0 |
| `REQ-LYR-05` | 无歌词引导 AI 生成 | 无歌词 → 点"生成歌词" | 跳转/唤起歌词提取流程 | P0 |

### 4.2 行为驱动产品验收场景 (Gherkin Scenarios)

```gherkin
Feature: 歌词显示与编辑

  Scenario: REQ-LYR-01/.02 歌词展示与跳转 (Happy Path)
    Given 曲目《晚风》在同目录存在《晚风.lrc》
    When 用户进入播放页并切换到歌词视图
    Then 歌词逐行显示，当前行以高亮色突出并自动居中
    When 用户点击第 10 行歌词
    Then 播放进度立即跳到第 10 行的时间戳

  Scenario: REQ-LYR-03 偏移同步微调 (Adjustment)
    Given 歌词整体比演唱慢 1 秒
    When 用户在歌词页把偏移调整为 -1.0s 并保存
    Then 高亮行与演唱实时对齐
    And 音频同目录生成更新后的《晚风.lrc》，音频文件本体未被修改

  Scenario: REQ-LYR-05 无歌词时的出路 (Empty State)
    Given 曲目《旧信》没有任何歌词来源
    When 用户打开歌词视图
    Then 显示"这首歌还没有歌词"，并提供「生成歌词（本地 AI）」与「手动粘贴歌词」两个操作
```

## 5. 页面四态要求

- **Empty**：如上（含两个出路 CTA）；
- **Loading**：歌词文件解析瞬时完成，无需加载态；
- **Populated**：滚动高亮歌词（原文 + 翻译双行）；
- **Error**：.lrc 格式损坏 → "歌词文件格式异常，已按纯文本展示"。
