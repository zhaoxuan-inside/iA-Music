## 2. PROD-06 演练脚本（5 条核心场景 + 关键例外）

### 场景 1：引导 30 秒闭环（FTUE）
- 建议设置：页面=引导 · 视口=移动 · 四态依次：正常 → 加载 → 错误
- 走查步骤（状态由四态切换呈现）：
  - 正常态："你的音乐放在哪？" + 『音乐』文件夹卡（已发现 120 首；[采用] / [选择其他文件夹]）+ "下一步：试试提取你的第一首歌（可跳过）"
  - 加载态：扫描进度（已发现 128 首… · 扫描 2/3 个目录）
  - 错误态："⚠ 无法访问该文件夹" + [重新选择文件夹] / [跳过，直接开始]
- 预期观察：单屏即表达主步骤（≤3 屏）；扫描计数可见；下一步承接场景 2
- 注：REQ-ONB-03 合规声明门禁（首次触发提取时弹声明）在 demo 中未单列该屏——如需原型显式呈现请记为差异；声明回看入口在 设置页「合规声明 / 隐私（无遥测）」
- 关联：`REQ-ONB-*`；Gherkin「FTUE 30 秒闭环 / 合规门禁」

### 场景 2：提取主 Aha（链接 → 提取 → 沉浸播放）
- 建议设置：页面=提取 · 四态依次：空 → 正常 → 加载 → 错误
- 走查步骤（状态由四态切换呈现）：
  - 空态：粘贴框 + [开始提取] + 「如何获取链接（三步）」贴士
  - 正常态：结果卡（标题/UP/时长/码率 chips〔最高可用 320K〕/"将保存到 音乐仓库/提取/"）→ [开始提取 ★]；任务队列三行（进行中 72% · 2.1 MB/s · 剩 8s / 等待中 / ✓ 已完成 · 已加入曲库）
  - 加载态：[解析中 ⟳]
  - 错误态：toast"链接解析失败…你的输入已完整保留" + [登录 B 站] / [重试]
- 预期观察：主 Aha 路径 ≤3 步（链接→确认→入库）；错误态保留输入并给出修复动作
- 注：REQ-EXT-07 首次进入提取页的合规声明（同上，demo 未单列）
- 关联：`REQ-EXT-*`；Gherkin「主 Aha 五步骤 / 错误保留输入」

### 场景 3：垃圾桶（少播名单）+ 缺失跳过
- 建议设置：页面=播放 · 页面=曲库 · 页面=设置 · 播放页切 错误态
- 走查步骤（垃圾桶为静态示意）：
  - 播放页/随机页底部垃圾桶图标（title=不喜欢）→ 语义落点：设置页「少播名单 · 3 首」行
  - 曲库正常态第 3 行《旧信》：行灰显 + 徽标「文件缺失」
  - 播放页切 错误态：toast"《旧信》文件缺失，已跳过 → 正在播放《晚风》"
  - 曲库错误态：音乐仓库无法访问 → [重新连接] / [移除仓库]（移除=解除记录，不删文件）
- 预期观察：垃圾桶=少播名单语义（存在恢复路径）；缺失不阻塞播放、绝不删除文件
- 关联：`REQ-PLAY-02`、`REQ-LIB-*`（缺失恢复 / 移除≠删除）

### 场景 4：歌词生成闭环
- 建议设置：页面=歌词 · 四态依次：空 → 加载 → 正常 → 错误
- 走查步骤（状态由四态切换呈现）：
  - 空态："这首歌还没有歌词" + [生成歌词（本地 AI）★] / [手动粘贴歌词]
  - 加载态："识别中… 68%" + 进度条 + [取消] + "保持应用在前台可以获得更快速度"
  - 正常态：双语歌词（当前行高亮）+ 偏移（−0.5s / +0.5s）+ [保存歌词]
  - 错误态："歌词文件格式异常，已按纯文本展示。"（降级不假造）
- 预期观察：无假文件（失败给明示与出路）；生成语言=界面语言（DEC-005 DERIVED 顺带核对）
- 关联：`REQ-LYR-01/02`

### 场景 5：跨端同步 + 墓碑
- 建议设置：页面=同步 · 四态依次：空 → 正常 → 加载 → 错误
- 走查步骤（状态由四态切换呈现）：
  - 空态：通道列表（WebDAV 最稳定推荐…；GitHub 标注"仅同步歌单/歌词/元数据，不存音频"=门禁提示）
  - 正常态：已连接：WebDAV（上次同步 3 分钟前 · 待上传 2 · 待下载 5）+「冲突副本 (2)」+ 提示"ⓘ 删除同步仅传播记录，云端音频文件不会被自动删除。"
  - 加载态：首次同步中 34%（当前: 晚风.flac · 待 128/376）
  - 错误态：授权过期 → [重新授权] / [更换通道]
- 预期观察：通道状态可读；墓碑=仅传播记录、云端本体不动；GitHub 通道限制明示
- 关联：`REQ-SYNC-*`；Gherkin「跨端闭环 / 墓碑不毁云端 / GitHub 门禁」

### 关键例外速查（补充走查）

| 例外 | 在哪看 | 预期 |
|---|---|---|
| 空曲库 | 音乐空间 · 空态（曲库 · 空态同理） | 引导导入，不出现死胡同 |
| 索引损坏 | 搜索 · 错误态（「搜索索引损坏」→[重建索引]）；音乐空间 · 错误态（索引需要重建） | 给出重建动作；文件与收藏不受影响 |
| 同步异常 | 同步 · 错误态（授权过期） | [重新授权] / [更换通道] |
| 链接失效 / 需登录 | 提取 · 错误态 | 保留输入 + [登录 B 站] / [重试] |
| 歌词文件异常 | 歌词 · 错误态 | 降级纯文本展示，不假造 |
