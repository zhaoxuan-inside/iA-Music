# DEC-010 验证策略裁决：不要 Mock 数据

- **裁决日期**：2026-10-17
- **入场**：开发者原话『不要 Mock 数据。』（OpenCode 会话消息，2026-10-17）——响应阶段 4 Pack 中若干「Mock 边界」替身声明
- **裁决**：

| ID | 内容 |
|---|---|
| D10-1 | **验证一票全真**：测试与演练一律走真实数据源与真实集成——真库（drift/SQLite）、真文件、真引擎（mpv）、真网络（CAA/iTunes/B 站链路/模型 CDN）、真本地协议服务（WebDAV）；**禁止替身桩、录制回放、伪造数据源**（IMPL-04 严格化执行，取代「声明 Mock 范围」放宽口径） |
| D10-2 | **真实测试夹具不受影响**：真实存在的样本文件（短音频/纯音乐/损坏/零字节）、真实测试库（GitHub test repo）、真实本地 WebDAV 服务、真模型——夹具=真实事物，非伪数据源 |
| D10-3 | **缺真物即阻塞**：无真机时 RV-A/B/C 保持阻塞待开发者窗口，不得以替身降级通过；无网/失效态用真实操作制造（真实断开网络开关、真实清除 SecureStore 条目），不注入伪造值 |
| D10-4（开放点） | 性能压测所用的「合成 1 万行曲库」保留为最小可行基线（=真实代码路径写入的真实行，非伪造数据源）；若开发者要求改用真实曲库压测，验收时提出即改判 |

- **影响**：TASK-BREAKDOWN §5 / CP-S0..S10 / TASK-S1·S3·S5·S6·S7 同步修订；阶段 5 验收证据按本裁决复核（替身残留=0）。
- **来源**：本记录；受影响验收行=PHASE-4-ACCEPTANCE §7 变更记录、TASK-04。
