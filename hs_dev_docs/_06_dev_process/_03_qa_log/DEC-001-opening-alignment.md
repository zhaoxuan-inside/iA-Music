## 轮 1：开场对齐 O1～O4（已确认）

### O1 需求复述（开发者未提出修正 → CONFIRMED）

本地音乐播放器（Android / Windows / Linux）：指定本地目录为音乐仓库并播放管理；B 站分享链接提取音频入库；模型从音乐提取歌词；GitHub 及其他云盘同步；UI 参照 Uptodown 豆瓣 FM 7.1.2.1 风格。

**反目标（本期拟不做，待 MVP 裁定时逐项拍板）**：在线流媒体/版权曲库、社交与评论、iOS/macOS、音乐推荐电台算法。

## 视觉参照证据（DERIVED，来源：App Store 豆瓣 FM 7.1.2 官方截图）

落盘：`_01_product_vision/_01_design_charter/reference/doubanfm-7.1.2/`（4 张，含播放页/发现页/搜索页/我的页）

观察到的视觉气质（待 DESIGN.md 正式定义，证据级推导）：

- 深色沉浸底（近黑），播放页由封面主导的模糊背景；
- 品牌绿为唯一强调色（播放/收藏/VIP 等 CTA）；
- 大圆角封面/卡片；极简播放三键（垃圾桶 / 播放 / 下一首）+ 红心；
- 底部迷你播放条（pill）+ 三 Tab（发现 / 搜索 / 我的）；
- 大标题（28-32px bold）+ 灰色小标题（14px）层级。
